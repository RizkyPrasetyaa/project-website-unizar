# UNIZAR Fakultas (React)

## Jalankan

```bash
cd unizar-fakultas-ready
npm install
npm run dev
```

Buka: http://localhost:5173/fakultas

## Route
- /fakultas — daftar fakultas & prodi (klik)
- /fakultas/kedokteran — detail fakultas
- /prodi/ilmu-komputer — detail prodi + kurikulum
